# Workout App — Frontend

React Native mobile app for logging workouts and tracking calories, including AI-powered food recognition for Indian cuisine.

## Features
- Workout and set logging
- Macro/calorie tracking
- Food photo capture, classified by a custom CNN ([food-recognition-cnn](https://github.com/balloon083/food-recognition-cnn)) via the [backend API](https://github.com/balloon083/workout-app-backend)

## Stack
React Native, TypeScript

## Setup
```bash
git clone https://github.com/balloon083/workout-app-frontend
cd workout-app-frontend
npm install
npm start
```
